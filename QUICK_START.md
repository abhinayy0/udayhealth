## 🆘 Common Issues & Solutions

### Issue 1: "Website looks broken"
**Solution:** Upload ALL files, not just index.html
- index.html
- styles.css
- script.js
- images folder (with all images)
- admin.html

### Issue 2: "Changes not showing"
**Solution:** 
1. Clear browser cache (Ctrl+F5)
2. Wait 2 minutes
3. Check if you uploaded the NEW index.html

### Issue 3: "Can't find admin.html"
**Solution:** 
1. It's in the same folder as index.html
2. Open it with Chrome/Firefox
3. Or go to: yoursite.netlify.app/admin.html

### Issue 4: "Download button not working"
**Solution:**
1. Make sure you're running from a web server
2. Use `make serve` first
3. Then open http://localhost:8000/admin.html
