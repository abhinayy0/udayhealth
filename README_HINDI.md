# 🏥 उदय हेल्थ केयर वेबसाइट - सामग्री अपडेट गाइड

## 📝 बिना कोडिंग के वेबसाइट कैसे अपडेट करें

### ✨ सबसे आसान तरीका

#### चरण 1: एडिटर खोलें
1. `admin.html` फ़ाइल को किसी भी ब्राउज़र में खोलें (Chrome, Firefox, Edge)
2. आपको एक सरल फॉर्म दिखाई देगा

#### चरण 2: सामग्री बदलें
1. जो भी टेक्स्ट बदलना है, बदलें (फोन नंबर, पता, विवरण)
2. अंग्रेजी और हिंदी दोनों संस्करण बदलें
3. "Save Changes" बटन पर क्लिक करें

#### चरण 3: डाउनलोड और अपलोड करें
1. "Download Updated Website" बटन पर क्लिक करें
2. डाउनलोड की गई `index.html` फ़ाइल को अपनी होस्टिंग पर अपलोड करें

---

## 🆓 मुफ्त होस्टिंग विकल्प

### विकल्प 1: Netlify Drop (सबसे आसान)

**क्यों चुनें?**
- ✅ पूरी तरह से मुफ्त
- ✅ खाता बनाने की जरूरत नहीं
- ✅ 2 मिनट में अपडेट
- ✅ प्रोफेशनल URL

**कैसे उपयोग करें:**
1. https://app.netlify.com/drop पर जाएं
2. सभी वेबसाइट फ़ाइलों को ड्रैग करें
3. मुफ्त URL मिलेगा: `yoursite.netlify.app`
4. अपडेट करने के लिए: नई फ़ाइलें फिर से ड्रैग करें!

### विकल्प 2: GitHub Pages (मुफ्त)

1. https://github.com पर मुफ्त खाता बनाएं
2. नया repository बनाएं
3. वेबसाइट फ़ाइलें अपलोड करें
4. Settings में GitHub Pages enable करें
5. आपकी साइट: `yourname.github.io`

**सामग्री अपडेट करने के लिए:**
1. GitHub में `index.html` पर क्लिक करें
2. पेंसिल आइकन (Edit) पर क्लिक करें
3. बदलाव करें
4. "Commit changes" पर क्लिक करें
5. वेबसाइट अपने आप अपडेट हो जाएगी!

## 🆘 अगर कुछ गलत हो जाए

1. **वेबसाइट टूटी हुई दिखती है?**
   - सभी फ़ाइलें फिर से अपलोड करें
   - सुनिश्चित करें कि images फ़ोल्डर अपलोड हो गया है

2. **बदलाव नहीं दिख रहे?**

3. **मूल फ़ाइलें खो गईं?**
   - होस्टिंग सेवा से डाउनलोड करें
   - या आपके द्वारा बनाए गए बैकअप का उपयोग करें!
